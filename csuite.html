The news: attackers stopped bringing malware. They bring your IT tools.

Add-on briefing for the 2026 Chicago SMB Email Security Report, based on ANY.RUN research published September 22, 2026.

CSuite is a multi-stage operation that works like this: phishing email → Microsoft 365 account compromise → device-code authentication abuse → session hijacking → deployment of legitimate remote-management tools.

Read that last part again. The attackers don't install their own malware. They install ScreenConnect, Atera, Action1, Syncro, and PDQ Connect — the same remote tools a real IT department uses. Once they're in, the attack looks like normal IT administration. There is no virus to catch.

The lures impersonate Adobe, DocuSign, Zoom, SharePoint, and ordinary Microsoft 365 workflows. 60% of the identified victim organizations are in the United States. This is not a nation-state story. This is shops the size of yours.

What this means for your shop

  1. Your remote tools are the attack surface. If you run ScreenConnect, Atera, or similar on endpoints, an attacker with a phished M365 session gets the same screen you do. Lock down who can install and run remote-access software — and treat any unexpected remote session as an incident, not a glitch.
  2. Device-code phishing beats MFA. The attack abuses the "sign in on another device" flow your employees use legitimately. Train staff: if anyone — even someone claiming to be IT — asks you to enter a code from an email or screen into a Microsoft login page, stop and verify through a channel you trust.
  3. Blocking malware isn't enough anymore. When the attacker's toolkit is your own software, prevention shifts to identity: phishing-resistant authentication, conditional access, and monitoring for impossible-travel and odd session behavior.
