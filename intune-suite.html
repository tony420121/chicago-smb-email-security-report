The Intune Suite you already own: a free upgrade hiding in your tenant.

On July 1, 2026, Microsoft folded roughly $10/user/month of Intune Suite features into M365 E3/E5 at no extra cost. Most shops never turned any of them on. This is the checklist: what you're already paying for, where it hides, and the 3 to activate first.

What Microsoft gave you (quietly)

Intune Suite used to be a paid add-on — about $10 per user per month — which is why most small shops never bought it. Effective July 1, 2026, its capabilities are included in Microsoft 365 E3 and E5 licenses. You're already paying for this. Here's what landed in your tenant:

Remote Help

Secure, policy-controlled screen-sharing and remote assistance built into Intune — your IT person helps a user's PC without a third-party remote-access tool (and without the licensing bill).

Where it hides: Intune admin center → Tenant administration → Connectors and tokens → Remote Help. Needs an Intune license on both ends and a support role assigned.

Endpoint Privilege Management (EPM)

Lets standard users run specific approved apps "as admin" without being local admins — the single biggest fix for the "everyone has admin rights" problem that malware depends on.

Where it hides: Intune admin center → Endpoint security → Endpoint Privilege Management. Configure elevation policies for your known apps, then remove local admin rights.

Advanced Analytics

Per-device health scoring, boot and sign-in performance trends, and hardware readiness reports — the data you need to know which machines are slowing people down (and which are ready for the next Windows upgrade).

Where it hides: Intune admin center → Reports → Endpoint analytics. Data collection is on by default once licensed; the dashboards need reviewing, not installing.

Enterprise App Management (App Catalog)

Curated, auto-updating catalog of common business apps — deploy and patch Chrome, Adobe Reader, Zoom, and dozens more from Intune without packaging installers yourself.

Where it hides: Intune admin center → Apps → Enterprise app catalog. Pick the apps, assign to device groups, done.

Cloud PKI

Cloud-issued certificates for Wi-Fi and VPN authentication — no certificate server to build or maintain.

Where it hides: Intune admin center → Devices → Configuration → Cloud PKI. Requires certificate-authority configuration first; skip this one if you're a simple shop.

Tunnel for MAM

VPN-style per-app access for mobile devices without a full device VPN — mostly relevant if you manage company phones or BYOD.

Where it hides: Intune admin center → Tenant administration → Microsoft Tunnel Gateway. Mobile-heavy shops only.

Honest note on licensing: this bundling applies to M365 E3/E5 tenants. If you're on Business Premium, E1, or standalone plans, the exact feature set differs — check your license terms before assuming a feature is included. And if you're not sure which license you hold, ask whoever sends you the Microsoft bill.

The 3 to activate first

Don't try to turn everything on this week. Start here, in this order:

1. Enterprise App Management. Point it at your top 3–5 business apps and let the catalog handle updates. Patching stops being a monthly project and starts being automatic. Biggest time savings for the least effort.
2. Endpoint Privilege Management. Set elevation rules for your known apps, then pull local admin rights from daily user accounts. This one change removes the permission malware needs most.
3. Advanced Analytics. Look at the Endpoint analytics dashboard and find your slowest-booting, least-healthy machines. This is your evidence-based hardware refresh list — and it answers the "which computers need replacing" question without guessing.

Print this page and hand it to your IT person. Everything above is built into your tenant already — no purchases, no third-party tools, no projects. Just activation.
