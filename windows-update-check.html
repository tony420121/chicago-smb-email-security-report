Will your computer still get security updates? The 10-second check.

On October 13, 2026 — nine days from now — Windows 11 24H2 Home and Pro stop receiving updates. The mainstream press is carrying the warning, and the question every owner asks is the simplest one: is that me? Here's the 10-second check.

The 10-second check

On each Windows PC: press Win+R, type winver, press Enter. Read the version number. That's the whole check.

The four answers

  • 24H2 (Home or Pro) — act now. End of updates October 13, 2026. Update to 25H2 to keep receiving monthly security and quality updates.
  • 25H2 — you're safe until October 2027. Nothing to do.
  • 26H2 — you're done. Already current.
  • 26H1 — the trap. You can't jump straight to 26H2 from here; it needs its own path. Don't assume the updater will offer you the newest version.

One stranded outlier: Windows 11 SE tops out at 24H2 — no newer version exists for it. Those machines need a replacement plan, not an update.

What "end of updates" actually means — Microsoft's own wording: the machine keeps working, but it stops receiving monthly security and non-security updates, including protections from the latest threats. It doesn't brick. It just stops getting safer.

The honest version

This page is written for the one-person IT shop — the owner who is the IT department — not the home PC. (If that's you at home, the check still works; the stakes are just lower.) Nine days is enough. The 24H2 → 25H2 update is the standard update path for most machines — but don't discover your one weird machine on October 14. Run the check this week.

Three actions — this week

1. Run winver on every Windows PC

Servers, front-desk machines, the laptop in the back room. Write down each version. The one you forgot is the one that matters.

2. Move every 24H2 machine to 25H2

Settings → Windows Update, or your usual patch process. Verify with winver afterward — "it said it updated" isn't verification.

3. Make a plan for the outliers

26H1 machines need their proper upgrade path; Windows 11 SE machines need replacing. Put both on a list with dates — "later" is how machines end up unpatched.
